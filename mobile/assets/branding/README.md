# StickStat app-logo

Plaats het definitieve, vierkante app-logo hier als `app_logo.png`.

- PNG
- minimaal 512 × 512 pixels
- bij voorkeur 1024 × 1024 pixels
- houd belangrijke onderdelen weg van de buitenste rand, omdat Android iconen kan afronden

`scripts/build-apk.ps1` maakt tijdens de build automatisch de Android launcher-iconen.
